# '3urfti (غرفتي)

A web app that helps Arab college students find compatible roommates, make friends, and build community.

## How to open it

1. Open this folder.
2. Double-click **`index.html`**. It opens in your web browser.
3. Click **Sign Up** to make an account, or **Log In → Demo (female) / Demo (male)** to jump straight in.

No installing needed. You do need internet the first time, because the styling (Tailwind CSS) and fonts load from the web.

## What's inside

| File | What it controls |
|---|---|
| `index.html` | The front cover (landing page) and the Sign Up / Log In pop-ups |
| `dashboard.html` | The Discover page: filters, student cards, profile pop-up, chat helper |
| `js/i18n.js` | **Every word on the site** in English and Arabic |
| `js/data.js` | Universities, interests, and the 24 sample students |
| `css/styles.css` | Extra styling (fonts, chips, animations) |
| `ARCHITECTURE.md` | The full plan for the real app: server, database, AI chatbot |

Your accounts and requests are saved only in **your** browser. Clearing your browser data resets everything.
